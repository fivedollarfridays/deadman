# Integration gate: demo, README, architecture diagram

The contest scores demo and production readiness at thirty percent and requires
a live unedited demo. Rehearse a break-and-heal sequence end to end, commit real
sample outputs generated by script, and verify a clean clone reproduces.

# Acceptance Criteria

- [x] `docs/DEMO.md` scripts a break-and-heal sequence runnable in one unedited take — eight stages driven by `scripts/demo.py`: healthy canary, relay starts returning 503, detection by active canary, live Gemini diagnosis, correlator declining to invent a pattern from one fault, deterministic cause-keyed selection, act-then-re-observe, and self-liveness with an out-of-band alarm. Every layer is shipped code. The one simulated component is the phone relay, labelled in the script, in DEMO.md, and to be said out loud on camera.
- [x] The sequence has been rehearsed end to end at least once and the runtime recorded — rehearsed four times live against real Gemini on 2026-08-11. **4.6s, 7.8s, 7.0s, 10.5s**; the spread is entirely model latency. Full table in `docs/DEMO.md`.
- [x] `sample-outputs/` is regenerated by a committed script, never hand-written — `scripts/generate_samples.py` writes all five files. `tests/test_sample_outputs.py` regenerates into a temp directory and compares byte for byte, plus asserts two consecutive runs are identical, so a hand-tidied sample fails the suite. Host-specific numbers are redacted rather than invented.
- [x] `docs/architecture.png` shows the deterministic and inferential layers distinctly — three bands: deterministic detect, an amber dashed inferential band containing only Gemini diagnosis and correlation with an explicit "what the model may never do" panel, and deterministic act-and-verify. Source is `docs/architecture.svg`, rendered by `scripts/render_diagram.sh`.
- [x] README opens with what it is and why it differs, not with installation — opens on the failure class that does not page anyone and the 24-day silent outage behind it. Installation is under "Run it", after the architecture argument. Ends with a Known limits section listing five real gaps.
- [x] Full suite green, `ruff check` clean, `bpsai-pair arch check --strict` clean — 236 passed (up from 222); `ruff check .` and `ruff format --check .` clean; `arch check --strict` clean apart from the pre-existing `.claude/hooks/base_branch_guard.py` warning, which is bpsai-pair scaffolding and predates this sprint.
- [x] A clean clone reproduces setup following only the README — verified by executing the README's commands verbatim against a fresh `git clone` from GitHub: venv, `pip install -e '.[dev]' -c constraints.txt`, `pytest -n auto --dist=worksteal` 236 passed, `python scripts/demo.py` completing, and `deadman-self-check` exiting 1 on a missing log.
